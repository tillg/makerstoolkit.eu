Terminal

Teil I · Basics · ca. 10 Min. · Braucht: –

Das Terminal ist ein Fenster, in dem man dem Computer Befehle als Text gibt, statt zu klicken. Claude Code lebt im Terminal – dort kann es Dateien lesen, Programme starten und Ergebnisse prüfen. Keine Angst: Die Befehle tippt meistens Claude, nicht du.

  • Mac & Linux: Ghostty – ein schnelles, modernes Terminal. Neuer Tab mit Cmd + T, Fenster teilen mit Cmd + D (z. B. links Claude, rechts ein zweites Terminal).
  • Windows: Windows Terminal (ist auf Windows 11 schon dabei).
  • Alternativ: das Terminal direkt in VS Code (Terminal → Neues Terminal).

Ordner und Wege

Alle Dateien liegen in einem Baum aus Ordnern (englisch Directories). Ganz oben steht die Wurzel /. Darunter die wichtigsten Ordner auf dem Mac:

/                    Wurzel: hier fängt alles an
├── Applications     Programme (Safari, VS Code …)
├── Library          Einstellungen und Hilfsdateien für alle Nutzer
├── System           macOS selbst, nicht anfassen
├── Users            die Home-Ordner aller Nutzer
│   ├── anna         Home von Anna:  /Users/anna
│   ├── ben          Home von Ben:   /Users/ben
│   └── tgartner     Home von Till:  /Users/tgartner
├── Volumes          USB-Sticks und externe Festplatten
├── bin, usr         Grundbefehle des Systems (ls, cd …)
├── etc              Einstellungen des Systems
└── tmp              Zwischendateien, wird regelmäßig geleert

Linux sieht fast gleich aus, nur heißen die Home-Ordner /home/anna. Unter Windows beginnt der Baum mit dem Laufwerk: C:\, die Home-Ordner liegen in C:\Users\anna.

Ein Pfad beschreibt den Weg durch den Baum: /Users/anna/mein-projekt/ideen.md.

Kurzzeichen

  • ~: dein Home-Ordner. Auf dem Mac z. B. /Users/tgartner, unter Linux /home/tgartner, unter Windows C:\Users\tgartner. ~/mein-projekt ist also /Users/tgartner/mein-projekt.
  • .: der Ordner, in dem du gerade bist.
  • ..: der Ordner eine Ebene höher.

Die wichtigsten Befehle

Befehl Was passiert
pwd Zeigt, wo du gerade bist.
ls -al Zeigt alle Dateien im Ordner, auch versteckte (die mit . anfangen), mit Größe und Datum.
cd mein-projekt Geht in den Ordner mein-projekt.
cd .. Geht eine Ebene höher.
cd ~ Geht zurück in deinen Home-Ordner.
Tab Vervollständigt. Tippe cd mei und drück Tab, das Terminal ergänzt zu cd mein-projekt/.
