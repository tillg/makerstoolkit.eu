Programm und Modell

Das Programm, das du bedienst (der Client), ist nicht die KI selbst. Die eigentliche KI ist ein großes Sprachmodell (LLM), das in der Cloud läuft. Der Client schickt deine Nachricht dorthin und zeigt die Antwort an.

Claude-App und Claude Code nutzen dasselbe Modell. Der Unterschied: Die App chattet mit dir, Claude Code darf zusätzlich Dateien in deinem Projekt lesen und schreiben und Befehle ausführen.

Die erste Session

  1. Lege einen Ordner an, z. B. mein-projekt.
  2. Öffne ihn in VS Code (Datei → Ordner öffnen).
  3. Öffne das Terminal in VS Code (Terminal → Neues Terminal) und tippe claude.
  4. Probier aus:
    • „Was befindet sich in diesem Ordner?“
    • „Lege eine Datei ideen.md an mit drei Ideen für ein Projekt zum Thema …“
    • „Mach aus der Liste eine Tabelle mit Spalten für Aufwand und Spaßfaktor.“

Neue Zeile und Bilder

Stand 2026-11 (Claude Code 2.1).

  • Neue Zeile: Enter schickt sofort ab. Für eine neue Zeile drückst du Strg+J (geht überall) oder tippst \ und dann Enter. Shift+Enter geht in vielen Terminals auch. Im VS-Code-Terminal erst, nachdem du einmal /terminal-setup eingegeben hast.
  • Bild einfügen: Mach einen Screenshot in die Zwischenablage (Mac: Cmd+Ctrl+Shift+4, Windows: Win+Shift+S). Dann in Claude Code Strg+V drücken, auch auf dem Mac (nicht Cmd+V). Unter Windows ggf. Alt+V. Im Eingabefeld erscheint [Image #1]. Dahinter schreibst du, was Claude damit tun soll: „Was ist auf diesem Bild falsch?“
  • Oder: Bilddatei ins Terminal ziehen (Drag & Drop) oder den Pfad nennen: „Schau dir fotos/karte.png an.“

Trick: ELI5. Claude fragt oder schreibt etwas, das du nicht verstehst? Tippe einfach ELI5. Das heißt Explain Like I'm 5 („Erklär es mir, als wäre ich fünf“). Claude erklärt es dann noch einmal ganz einfach, ohne Fachwörter.

Berechtigungen und Modi

Stand 2026-11 (Claude Code 2.1). Wortlaut und Voreinstellung ändern sich.

Claude Code fragt um Erlaubnis, bevor es Dateien ändert, Befehle ausführt oder ins Internet geht. Dateien im Projektordner lesen darf es immer. Du bist die Chefin, Claude ist der Assistent.

Eine Abfrage lesen

  1. Was will Claude tun? (Datei anlegen, Befehl ausführen …)
  2. Wo? Nur im Projektordner?
  3. Verstehe ich das? Wenn nicht: Nein wählen und fragen: „Erklär mir, was dieser Befehl tut.“
Deine Antwort Was passiert
Ja Einmal erlauben.
Ja, und nicht mehr fragen Claude merkt sich diese Art Aktion. Bei Befehlen gilt das dauerhaft für dieses Projekt. Sparsam nutzen.
Nein, mit Tab eine Begründung tippen Ablehnen und umsteuern: „Zeig mir erst, welche Dateien das wären.“
Esc Bricht den ganzen Arbeitsschritt ab.

Manchmal stellt Claude selbst eine Frage mit Auswahl, z. B. im Plan-Modus: „Welche Variante willst du?“ Mit den Pfeiltasten wählen, Enter. Passt keine? Eigene Antwort tippen.

Die Modi

Der Modus steht unten in der Fußzeile. Wechseln mit Shift+Tab (Windows ggf. Alt+M).

Modus Fußzeile Claude fragt …
Manual manual mode on vor jeder Änderung und jedem Befehl. Zum Lernen.
Accept edits accept edits on nicht mehr bei Dateien. Achtung: Auch Löschen und Verschieben im Ordner läuft dann ohne Frage.
Plan plan mode on gar nicht, denn Claude ändert nichts, es plant nur (Plan-Modus).
Auto auto mode on fast nie. Ein zweites Modell prüft im Hintergrund und stoppt Gefährliches, z. B. git reset --hard (verwirft Änderungen) oder Programme aus dem Internet ausführen.

Claude startet normalerweise im Auto-Modus. Im Kurs schalten wir am Anfang auf Manual, damit du die Abfragen lesen lernst.

Direkt im richtigen Modus starten

claude --permission-mode auto      # Auto: zügig arbeiten, dein Normalfall nach dem Kurs
claude --permission-mode manual    # Manual: jede Aktion selbst freigeben
claude --permission-mode plan      # Plan: erst planen, dann bauen
  • Vor Auto committen. Dann kannst du mit Git alles zurückholen.
  • /permissions zeigt, was du mit „nicht mehr fragen“ erlaubt hast. Dort kannst du es auch wieder löschen.
  • „Bitte frag nicht“ im Prompt ändert nichts. Die Regeln setzt das Programm durch, nicht Claude.
  • Nie --dangerously-skip-permissions oder den Modus „bypass permissions“ benutzen. Dann prüft gar nichts mehr.

Claude Code bedienen

Taste Was passiert
Enter Schickt ab, auch einen halben Satz!
Strg+J Neue Zeile (statt Enter)
Esc Stoppt Claude. Dann Korrektur tippen.
Esc Esc Zurückspulen auf einen früheren Stand (bei leerer Eingabe)
Shift+Tab Modus wechseln (Windows ggf. Alt+M)
@datei.md „Schau dir genau diese Datei an.“
/ Befehle, z. B. /clear (neues Gespräch), /resume (altes Gespräch), /model (Modell), /usage (Limit)
? Alle Tastenkürzel

Zurückspulen ersetzt Git nicht: Es erwischt nicht alles. Vor größeren Aufgaben committen.

Optional: Modell, Effort und Abo-Limits

Stand 2026-11. Modelle und Limits ändern sich oft.

  • Claude Pro hat ein Kontingent für 5 Stunden und eines für die Woche. Chat im Browser und Claude Code teilen es sich.
  • Mit /usage siehst du, wie viel schon verbraucht ist. In der Claude-App: Einstellungen → Nutzung.
  • Mit /model wählst du das Modell. Voreingestellt ist Opus, Sonnet ist günstiger. In der Claude-App wählst du das Modell unten im Eingabefeld.
  • Claude hat kein Gedächtnis: Bei jeder Runde wird das ganze Gespräch neu geschickt. Lange Gespräche kosten mehr. Neue Aufgabe → /clear. Nach einer langen Pause auch.
  • Erst Effort, dann Modell. Mit /effort stellst du ein, wie gründlich Claude arbeitet (low, medium, high …). Das Modell mitten im Gespräch zu wechseln ist teuer.
  • Für eine einzelne schwere Frage: ultrathink in den Prompt schreiben.
  • Auf Pro nicht einschalten: das Modell Fable und /fast. Beides kostet dort extra Geld.
  • Mehrere Agenten gleichzeitig verbrauchen ein Vielfaches.
