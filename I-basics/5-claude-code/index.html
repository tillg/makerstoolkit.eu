Chatbot vs. Agent

Chatbot Agent
Du fragst, er antwortet Du gibst eine Aufgabe, er erledigt sie
Kopieren & Einfügen Liest und schreibt Dateien direkt in deinem Projekt
Ein Schritt Viele Schritte: lesen, planen, ausführen, prüfen

Programm und Modell

Das Programm, das du bedienst (der Client), ist nicht die KI selbst. Die eigentliche KI ist ein großes Sprachmodell (LLM), das in der Cloud läuft. Der Client schickt deine Nachricht dorthin und zeigt die Antwort an.

Claude-App und Claude Code nutzen dasselbe Modell. Der Unterschied: Die App chattet mit dir, Claude Code darf zusätzlich Dateien in deinem Projekt lesen und schreiben und Befehle ausführen.

Die erste Session

  1. Lege einen Ordner an, z. B. mein-projekt.
  2. Öffne ihn in VS Code (Datei → Ordner öffnen).
  3. Öffne das Terminal in VS Code (Terminal → Neues Terminal) und tippe claude.
  4. Probier aus:
    • „Was befindet sich in diesem Ordner?“
    • „Lege eine Datei ideen.md an mit drei Ideen für ein Projekt zum Thema …“
    • „Mach aus der Liste eine Tabelle mit Spalten für Aufwand und Spaßfaktor.“

Trick: ELI5. Claude fragt oder schreibt etwas, das du nicht verstehst? Tippe einfach ELI5. Das heißt Explain Like I'm 5 („Erklär es mir, als wäre ich fünf“). Claude erklärt es dann noch einmal ganz einfach, ohne Fachwörter.

System Prompt und so

  • Was passiert lokal, was am Server
  • Wie wird das Prompt zusammengestellt
  • Lokale Tools
  • Rechte oder nicht
  • Claude startet im Auto-Modus: Ein zweites Modell prüft im Hintergrund und erlaubt Harmloses selbst. Für den Anfang schalten wir auf manual (einmal Shift+Tab, unten steht dann manual mode on). Dann fragt Claude nach, bevor es Dateien ändert oder Befehle ausführt. Lies, was es vorhat, bevor du zustimmst. Du bist der Chef, Claude ist der Assistent. (Stand 2026-11)

Claude Code bedienen

Taste Was passiert
Enter Schickt ab, auch einen halben Satz!
Strg+J Neue Zeile (statt Enter)
Esc Stoppt Claude. Dann Korrektur tippen.
Esc Esc Zurückspulen auf einen früheren Stand (bei leerer Eingabe)
Shift+Tab Modus wechseln (Windows ggf. Alt+M)
@datei.md „Schau dir genau diese Datei an.“
/ Befehle, z. B. /clear (neues Gespräch), /resume (altes Gespräch), /model (Modell), /usage (Limit)
? Alle Tastenkürzel

Zurückspulen ersetzt Git nicht: Es erwischt nicht alles. Vor größeren Aufgaben committen.

Optional: Modell, Effort und Abo-Limits

Stand 2026-11. Modelle und Limits ändern sich oft.

  • Claude Pro hat ein Kontingent für 5 Stunden und eines für die Woche. Chat im Browser und Claude Code teilen es sich.
  • Mit /usage siehst du, wie viel schon verbraucht ist. In der Claude-App: Einstellungen → Nutzung.
  • Mit /model wählst du das Modell. Voreingestellt ist Opus, Sonnet ist günstiger. In der Claude-App wählst du das Modell unten im Eingabefeld.
  • Claude hat kein Gedächtnis: Bei jeder Runde wird das ganze Gespräch neu geschickt. Lange Gespräche kosten mehr. Neue Aufgabe → /clear. Nach einer langen Pause auch.
  • Erst Effort, dann Modell. Mit /effort stellst du ein, wie gründlich Claude arbeitet (low, medium, high …). Das Modell mitten im Gespräch zu wechseln ist teuer.
  • Für eine einzelne schwere Frage: ultrathink in den Prompt schreiben.
  • Auf Pro nicht einschalten: das Modell Fable und /fast. Beides kostet dort extra Geld.
  • Mehrere Agenten gleichzeitig verbrauchen ein Vielfaches.
