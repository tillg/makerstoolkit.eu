1.2 Werkzeuge installieren

Dauer: ca. 10 Min. (Ziel: schon vor dem Workshop erledigt)

Worum geht's

Drei Werkzeuge: VS Code (Fenster zum Projekt), Git (Zeitmaschine, kommt in Teil II) und Claude Code (der Agent). Im Workshop prüfen wir nur, ob alles läuft. Installiert wird vorher.

Lernziel

Nach diesem Thema …

  • läuft bei jeder Person code/VS Code, git --version und claude mit erfolgreicher Anmeldung,
  • wissen die Teilnehmenden, was jedes der drei Werkzeuge tut,
  • haben sie bei Problemen einen klaren nächsten Schritt.

So erklären wir es

  1. Werkstatt-Bild: Wir bauen eine Werkstatt.

    VS Code ist der Arbeitstisch: Dort siehst du alle Dateien und kannst sie lesen. Claude Code ist die Assistentin, die am Tisch mitarbeitet. Git ist das Archiv, mit dem man jederzeit zu einem früheren Stand zurück kann. Dazu später mehr.

  2. Wer macht was:

    Werkzeug Rolle Wofür im Workshop
    VS Code Editor, Arbeitstisch Ordner öffnen, Markdown ansehen
    Git Zeitmaschine Teil II
    Claude Code Agent alles andere

  3. Check-Runde statt Installieren. Alle öffnen ein Terminal (Details in 1.3) und tippen drei Zeilen. Wer grün ist, hebt den Daumen.

  4. Zugang: Claude Code braucht ein Konto mit Abo oder Zugang (wie der Zugang läuft, haben wir per Mail geschickt, siehe organisation.md). Der kostenlose Chat-Plan enthält kein Claude Code (Stand 2026-11, [KB] 25, §Requirements and accounts).

  5. Git-Einrichtung einmalig (kommt vor dem ersten Commit, siehe 2.4; [OC] 5):

    Git muss wissen, wer du bist, damit es Änderungen unterschreiben kann. Das sind Name und E-Mail, einmal einstellen.

    Zwei weitere Einstellungen gleich mit: Der Standardname des ersten Zweigs (Git nutzt weiter master, bis Git 3.0 main einführt) und der Editor für Commit-Nachrichten, damit sich nicht das Terminal-Programm vim öffnet (Stand 2026-11, [KB] 24, §Install and one-time setup).

Zeigen (Live-Demo)

Check-Befehle am großen Bildschirm, alle tippen mit:

git --version
claude --version
claude

Beim ersten claude: Browser öffnet sich, anmelden, zurück ins Terminal. Öffnet sich kein Browser: c drücken kopiert den Anmelde-Link. Zeigt der Browser stattdessen einen Code, im Terminal bei „Paste code here“ einfügen. Dann Enter. Beim ersten Start in einem neuen Ordner fragt Claude, ob man ihm vertraut: Ja, aber nur in Projektordnern (siehe Stolpersteine). Dann „Hallo“ schreiben, Antwort abwarten, beenden mit /exit. VS Code: öffnen, einen Ordner öffnen.

Git-Konfiguration (einmal, eigene Daten einsetzen):

git config --global user.name "Dein Name"
git config --global user.email "du@example.com"
git config --global init.defaultBranch main
git config --global core.editor "code --wait"

init.defaultBranch main: neue Projekte starten auf main statt master. core.editor: Commit-Nachrichten öffnen sich in VS Code statt in vim (2.2, 2.4).

Selbst machen (Übung)

Ein Funktionstest: Terminal öffnen, claude starten, „Hallo“ schreiben, Antwort erhalten. Geschafft, wenn Claude antwortet. Wer schon fertig ist, hilft der Nachbarin.

Installationsbefehle (falls doch noch nötig; Quelle: offizielle Doku, Stand 2026-11, [KB] 25, §Install, verify, update):

  • macOS/Linux/WSL: curl -fsSL https://claude.ai/install.sh | bash
  • Windows PowerShell: irm https://claude.ai/install.ps1 | iex
  • Windows CMD: curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
  • Alternativen mit Paketmanager: macOS brew install --cask claude-code, Windows winget install Anthropic.ClaudeCode. Dort gibt es keine automatischen Updates, man aktualisiert selbst (brew upgrade claude-code bzw. winget upgrade Anthropic.ClaudeCode).
  • Danach neues Terminalfenster öffnen und claude --version prüfen (zeigt z. B. 2.1.322 (Claude Code)). claude doctor zeigt eine Diagnose, ohne eine Session zu starten.

Stolpersteine & Fragen

  • claude: command not found / „nicht erkannt“: Terminalfenster schließen und neu öffnen. Hilft das nicht: PATH-Problem, siehe Troubleshooting. claude doctor zeigt Diagnose.
  • PowerShell vs. CMD verwechselt: irm gehört in PowerShell, der curl … install.cmd-Befehl in CMD. Prompt mit PS C:\ = PowerShell.
  • Windows ohne Git: Funktioniert, Claude nutzt dann PowerShell. Git for Windows ist empfohlen (und für Teil II nötig).
  • macOS fragt nach Git-Installation: Bei git --version bietet macOS die Developer-Tools an. Zustimmen, dauert einige Minuten.
  • Installation zeigt keinen Fortschritt: Normal, kurz warten.
  • Uni- oder fremde Konten (ChatGPT, Gemini): ChatGPT-Konto: Codex CLI vorab einrichten, siehe 00-vorbereitung.md. Gemini: Die Gemini CLI bedient seit 2026-06-18 keine Google-AI-Pro/Ultra-Privatkonten und keine kostenlosen Einzelkonten mehr. Nachfolger ist die Antigravity CLI (agy), sie liest GEMINI.md und AGENTS.md (Stand 2026-11, [KB] 15, §Gemini CLI → Antigravity CLI (Google)). Vorbereitung entsprechend prüfen.
  • Claude fragt „Vertraust du diesem Ordner?“: Normal. Immer in einem Projektordner starten. Im Home-Verzeichnis gilt das Vertrauen nur für die Sitzung und die Frage kommt bei jedem Start wieder ([KB] 25, §First start).
  • Alter Laptop: Anforderung laut Doku macOS 13+, Windows 10 1809+, 4 GB RAM (Stand 2026-11-06).
  • Kosten/Limits: Nicht hier klären, siehe organisation.md.
