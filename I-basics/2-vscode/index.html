VS Code

Teil I · Basics · ca. 10 Min. · Braucht: –

VS Code ist ein Editor. Mit VScode liest und schreibt man Datein nackt, d.h. ohne Formatierung. Links die Dateien, in der Mitte der Inhalt, unten das Terminal.

  • Ordner öffnen: Datei → Ordner öffnen. Ein Projekt ist immer ein Ordner.
  • Terminal öffnen: Terminal → Neues Terminal. Dort startest du Claude mit claude.
  • Markdown-Vorschau: Rechtsklick auf eine .md-Datei → Vorschau öffnen (oder Cmd/Strg + Shift + V).
  • Änderungen sehen: Symbol Quellcodeverwaltung in der linken Leiste (mehr dazu bei Git).
