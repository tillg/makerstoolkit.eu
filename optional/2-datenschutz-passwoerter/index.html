Datenschutz & Passwörter

Optionales Thema · ca. 20 Min. · Braucht: Git

Datenschutz: Wo liegen meine Daten?

Was Wo
Deine Dateien im Projektordner auf deinem Laptop
Git-Verlauf (.git) auf deinem Laptop
Was du Claude schreibst und alles, was Claude dafür liest geht an Anthropic (Cloud)
Ein Projekt auf GitHub online, privat oder öffentlich, wie du es einstellst

Merke: Liest der Agent eine Datei, schickt er ihren Inhalt mit. „Liegt nur auf meinem Laptop“ stimmt dann nicht mehr ganz.

  • In den Datenschutz-Einstellungen von Claude nachsehen, ob deine Chats zum Training verwendet werden dürfen, und bewusst entscheiden.
  • Uni- oder Schulkonto? Dann gelten deren Regeln.
  • Nicht in den Projektordner: fremde vertrauliche Dokumente, Ausweise, Gesundheitsdaten, Passwörter.

Passwörter managen

  • Nutze einen Passwort-Manager: z. B. Bitwarden (kostenlos), die Apple-App „Passwörter“ oder 1Password. Dann hast du für jede Seite ein eigenes, starkes Passwort und musst dir nur eines merken.
  • Schalte die Zwei-Faktor-Anmeldung ein, vor allem bei E-Mail, GitHub und deinem KI-Konto.
  • Passwörter und API-Keys nie in normale Projektdateien schreiben. Der Agent würde sie lesen, und Git würde sie für immer speichern. Wenn nötig: in eine Datei .env und diese in .gitignore eintragen.
