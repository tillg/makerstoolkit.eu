O.6 Webseite bauen

Dauer: ca. 15 Min.

Worum geht's

Eine Visualisierung oder ein Lernleitfaden aus dem Workshop geht online. GitHub Pages hostet kostenlos, Jekyll macht aus Markdown eine Webseite, eine eigene Domain kostet ein paar Euro im Jahr und wird über DNS verbunden.

Lernziel

Nach diesem Thema können die Teilnehmenden …

  • ein öffentliches Repository mit GitHub Pages online stellen.
  • in zwei Sätzen sagen, was Jekyll macht.
  • erklären, was eine Domain ist, was sie kostet und wofür DNS da ist.

So erklären wir es

  1. GitHub Pages: GitHub stellt die Dateien aus dem Repository als Webseite online. Ein Schalter in Settings → Pages. Adresse name.github.io/projekt. Jeder Push aktualisiert die Seite. Kostenlos für öffentliche Repositories; öffentlich heißt, alles im Repo ist lesbar (Bezug zu O.1).
  2. Jekyll: „Ein Drucker für Webseiten.“ Rein gehen Markdown-Texte und eine Vorlage (_config.yml, Theme), raus kommen fertige HTML-Seiten. Läuft bei GitHub automatisch, nichts zu installieren.
  3. Domain: Ein Name wie segeltoern-kroatien.de, gemietet beim Registrar, ca. 5–15 €/Jahr für .de (Stand 2026-11).
  4. DNS: „Das Telefonbuch des Internets“: übersetzt Namen in IP-Adressen. Beim Registrar trägt man ein, dass der Name zu GitHub zeigt. Änderungen brauchen Minuten bis Stunden, bis sie überall ankommen.
  5. HTTPS: In GitHub Enforce HTTPS anhaken, das Zertifikat ist kostenlos.

Selbst machen (Übung)

Eigenes Projekt (oder eine Kopie ohne Vertrauliches) als öffentliches Repository auf GitHub, Pages einschalten, Adresse im Browser öffnen.

Geklappt, wenn die Seite unter name.github.io/projekt erscheint.

Stolpersteine & Fragen

  • Privates Repo: Pages braucht dann ein bezahltes Konto. Lösung: eigenes öffentliches Repo nur für die Seite.
  • 404 direkt nach dem Einschalten: ein, zwei Minuten warten, dann neu laden.
  • Seite zeigt README statt Visualisierung: Die Startseite muss index.html oder index.md heißen.
  • Eigene Domain geht nicht sofort: DNS braucht Zeit. Erst nach ein paar Stunden Fehler suchen.
  • Jekyll ignoriert Ordner mit _ am Anfang. Bei reinem HTML hilft eine leere Datei .nojekyll.
