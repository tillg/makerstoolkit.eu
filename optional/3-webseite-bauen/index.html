Webseite bauen

Optionales Thema · ca. 15 Min. · Braucht: GitHub, HTML & JavaScript

Deine Visualisierung oder dein Lernleitfaden soll online gehen, mit eigener Adresse? Das geht kostenlos mit GitHub Pages. Nur eine eigene Domain kostet ein paar Euro im Jahr.

Stand: November 2026. Preise und Einstellungen ändern sich, also selbst nachsehen.

GitHub Pages: GitHub stellt deine Seite online

Dein Projekt liegt schon auf GitHub? Dann fehlt nur ein Schalter: Settings → Pages → Branch main → Save. Nach ein, zwei Minuten ist die Seite online unter

https://dein-name.github.io/dein-projekt/
  • Kostenlos für öffentliche Repositories. Für private brauchst du ein bezahltes GitHub-Konto.
  • Öffentlich heißt: Jeder kann alles im Repository lesen. Also nichts Vertrauliches hineinlegen.
  • Eine HTML-Datei (z. B. deine Visualisierung) wird einfach angezeigt.
  • Jeder git push aktualisiert die Seite.

Claude fragen: „Stell dieses Projekt mit GitHub Pages online und sag mir die Adresse.“

Aus Markdown wird eine Webseite

Deine Texte schreibst du in Markdown, wie im ganzen Workshop. Ein kleines Programm macht daraus fertige Webseiten. Dieses Programm musst du nicht suchen oder lernen: Claude schreibt es dir.

  • Du schreibst nur die Texte. Menü und Design stehen in einer Vorlage, die Claude mit anlegt.
  • Änderst du einen Text, baut das Programm die Seiten neu. Claude kann es so einrichten, dass das bei jedem Push von selbst passiert.

Claude fragen: „Schreib mir ein Programm, das aus meinen Markdown-Notizen eine Webseite mit Startseite und Menü baut, und stell sie mit GitHub Pages online.“

Eigene Adresse: Domain und DNS

dein-name.github.io ist gratis. Willst du segeltoern-kroatien.de, brauchst du eine Domain. Die kaufst (genauer: mietest) du bei einem Anbieter (Registrar), z. B. bei GoDaddy. Kosten: etwa 5–15 € pro Jahr für .de, andere Endungen oft mehr. Achte auf den Preis ab dem zweiten Jahr: Das erste Jahr ist oft ein Lockangebot.

DNS ist das Telefonbuch des Internets. Computer finden sich über Nummern (IP-Adressen), Menschen merken sich Namen. DNS übersetzt den Namen in die Nummer:

segeltoern-kroatien.de ──► DNS: „wohnt bei GitHub“ ──► GitHub zeigt deine Seite

So verbindest du beides:

  1. Domain beim Anbieter kaufen, z. B. bei GoDaddy.
  2. In GitHub: Settings → Pages → Custom domain eintragen.
  3. Beim Anbieter im DNS einen Eintrag anlegen, der auf GitHub zeigt. Welchen, steht in der GitHub-Hilfe zu custom domains. Claude kann dir dabei helfen.
  4. Warten: Bis die Änderung überall bekannt ist, dauert es Minuten bis Stunden.
  5. In GitHub Enforce HTTPS anhaken. Dann gibt es das Schloss im Browser, kostenlos.
