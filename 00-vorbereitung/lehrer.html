Vorbereitung

0.0 Vor dem Workshop

Worum geht's

Pflicht für die Teilnehmenden ist nur: Laptop mit Ladekabel. Alles andere dürfen sie vorher installieren, müssen aber nicht. Wer es nicht geschafft hat, installiert im Workshop. Darauf bereiten wir uns vor.

Kursleitung: Checkliste

  • Vorbereitungs-Mail mit der Schüler-Seite verschicken. Betonen: nur Laptop ist Pflicht, Installieren vorher hilft aber allen.
  • Bei der Anmeldung abfragen: Betriebssystem, Apple-Chip oder Intel, schon ein Claude-Zugang? (organisation.md)
  • Zugänge für alle ohne eigenes Abo bereit (siehe organisation.md).
  • Demo-Projekt aufbauen und einmal durchspielen (demo-projekt/segeltoern).
  • Intro-Demo vorher einmal laufen lassen und das Ergebnis als Reserve speichern (Intro).
  • WLAN im Raum testen. Mehrfachstecker und Verlängerungskabel einpacken.
  • USB-Stick mit den Installern (VS Code, Git für Windows) als Reserve, falls das WLAN schwach ist.

Installations-Block im Workshop

Dauer: ca. 30 Min., direkt nach dem Intro. Wer schon alles hat, hilft dem Nachbarn oder probiert die Intro-Demo selbst.

Reihenfolge, wie auf der Schüler-Seite:

  1. VS Code
  2. Git (Mac: git --version im Terminal, dann die Apple-Entwicklerwerkzeuge installieren lassen. Großer Download, dauert im schwachen WLAN lange. Früh starten.)
  3. Die vier git config-Zeilen
  4. Claude Code
  5. Test: claude starten, anmelden, „Hallo“ schreiben

Geschafft, wenn bei allen Claude auf „Hallo“ antwortet.

Stolpersteine & Fragen

  • Mac-Download hängt: Mit dem nächsten Schritt (VS Code) weitermachen und später zurückkommen.
  • Windows: claude wird nicht gefunden: Terminal neu öffnen, damit es den neuen Pfad kennt.
  • Anmeldung klappt nicht: Zuerst im Browser bei claude.ai einloggen, dann claude neu starten.
  • Alter Laptop (unter macOS 13 bzw. Windows 10 1809): in Zweiergruppen mit jemandem zusammenarbeiten.
