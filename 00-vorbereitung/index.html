00 · Vorbereitung

Damit wir im Workshop direkt loslegen können und nicht mit Installieren beschäftigt sind, erledige bitte vorher die Pflicht-Punkte. Alles Optionale kannst du auch im Workshop nachholen.

1. Laptop & Software

Mindestanforderung, Stand 2026-11: macOS 13 oder neuer (Intel oder Apple-Chip), Windows 10 (ab Version 1809) oder neuer, mindestens 4 GB Arbeitsspeicher. Du hast einen Intel-Mac? Dann diktierst du mit dem Handy (siehe unten).

Pflicht:

  • Laptop mit Ladekabel (macOS, Windows oder Linux)
  • VS Code installieren: https://code.visualstudio.com/
  • Git installieren: https://git-scm.com/downloads (macOS: im Terminal git --version eingeben – fehlt Git, bietet macOS die Installation an. Das ist ein großer Download, bitte zu Hause machen). Danach einmal im Terminal eingeben (Name und E-Mail ersetzen):
    git config --global user.name "Dein Name"
git config --global user.email "du@example.com"
git config --global init.defaultBranch main
git config --global core.editor "code --wait"
    Die letzten zwei Zeilen sorgen dafür, dass dein Hauptzweig main heißt und Git zum Schreiben VS Code öffnet statt eines schwierigen Terminal-Editors.
  • Claude Code installieren: Anleitung unter https://code.claude.com/docs/en/setup

Optional (geht auch im Workshop):

  • In VS Code die Erweiterung Claude Code installieren
  • Ein modernes Terminal: auf Mac/Linux Ghostty (https://ghostty.org); unter Windows ist Windows Terminal schon dabei
  • Für mehrere Agenten gleichzeitig: herdr (https://herdr.dev)
  • Zum Diktieren: auf dem Mac (Apple-Chip) Hex installieren: https://hex.kitlangton.com – Mikrofon- und Bedienungshilfen-Zugriff erlauben. Unter Windows (oder auf älteren Macs) Handy installieren: https://handy.computer.

2. Zugang zu Claude

  • Account anlegen bzw. Zugang einrichten – wie genau, schicken wir dir vorab per Mail.
  • Du hast schon Claude Pro/Max? Super, nutze es. Du hast ChatGPT (Plus/Edu) oder Google Gemini, z. B. über die Uni? Sag uns Bescheid. Du kannst es nutzen, aber nur, wenn du es vorher zum Laufen gebracht hast (Codex CLI bzw. Antigravity CLI; die alte Gemini CLI geht mit privaten Google-Konten seit Juni 2026 nicht mehr). Im Workshop zeigen wir alles mit Claude Code oder anderen CLIs wenn jemand sie hat. Ein reiner Chat im Browser reicht nicht.
  • Pflicht: Einmal testen: Terminal öffnen, claude eingeben, anmelden, „Hallo“ schreiben. Kommt eine Antwort, bist du startklar.

3. Eigenes Material mitbringen

Such dir ein Thema aus, das dich interessiert, und bring 5–20 Dokumente dazu mit:

  • Studium/Schule: Vorlesungsskripte, Übungsblätter, Mitschriften, Paper (Physik, Mathematik, Wirtschaft …)
  • Freizeit: Reiseführer, Tourenbeschreibungen, GPX-Tracks, Hafenhandbücher, Skigebietsinfos, Blogartikel
  • Formate: PDF, Word, Text, Markdown, CSV, Bilder

Wichtig: Nur Material, das du verwenden darfst – nichts Vertrauliches.

Kein eigenes Thema? Kein Problem, wir haben Beispielmaterial dabei.

Probleme?

Melde dich vorher bei Till oder Henri – lieber vor dem Workshop als währenddessen.
