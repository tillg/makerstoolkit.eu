HTML & JavaScript

Teil V · Erschaffen & visualisieren · ca. 55 Min. · Braucht: Plan-Modus, Wissensbasis

Claude kann HTML und JavaScript schreiben: Webseiten mit Schiebereglern, Animationen, Diagrammen und Karten, die einfach im Browser laufen. Du beschreibst, Claude baut, du testest.

Selbst schreiben musst du das nicht. Aber wenn du ungefähr weißt, wie es aussieht, verstehst du besser, was Claude baut, und kannst gezielter Feedback geben.

Was ist HTML?

HTML beschreibt, was auf einer Webseite steht: Überschriften, Absätze, Bilder, Knöpfe, Schieberegler. Wie Markdown, nur ausführlicher. Jede Webseite im Internet ist HTML.

So ist es aufgebaut:

  • Alles steht in Tags (Etiketten) in spitzen Klammern: <h1> öffnet eine Überschrift, </h1> schließt sie wieder.
  • Tags stecken ineinander wie Schachteln. Ein Absatz <p> kann z. B. ein fett gedrucktes Wort <b> enthalten.
  • Manche Tags haben Attribute, also Zusatzangaben: <input type="range" min="0" max="10"> ist ein Schieberegler von 0 bis 10.
  • Eine Seite hat zwei Teile: <head> (Titel, Einstellungen, unsichtbar) und <body> (alles, was man sieht).
<!doctype html>
<html lang="de">
  <head>
    <title>Sparplan</title>
  </head>
  <body>
    <h1>Mein Sparplan</h1>
    <p>Wie viel Zinsen pro Jahr? <b id="zins-anzeige">3</b> %</p>
    <input id="zins" type="range" min="0" max="10" value="3">
    <p>Aus 1000 € werden in 10 Jahren: <b id="ergebnis">1344</b> €</p>
  </body>
</html>

Diese Seite zeigt eine Überschrift, zwei Sätze und einen Schieberegler. Aber: Der Regler tut noch nichts. Dafür braucht es JavaScript.

Das Aussehen (Farben, Schriften, Abstände) regelt eine dritte Sprache: CSS. Die schreibt Claude gleich mit.

Was ist JavaScript?

JavaScript (kurz JS) beschreibt, was passiert: rechnen, auf Klicks und Regler reagieren, Inhalte ändern, Animationen abspielen. Es läuft direkt im Browser, nichts zu installieren.

So ist es aufgebaut:

  • Eine Folge von Anweisungen, die der Browser der Reihe nach ausführt. Jede endet meist mit ;.
  • Variablen merken sich Werte: const startbetrag = 1000;
  • Funktionen sind kleine Rezepte, die man immer wieder aufrufen kann.
  • Über document.getElementById("…") greift JavaScript auf ein HTML-Element mit diesem id zu.
  • Mit addEventListener sagt man: „Wenn das passiert (z. B. der Regler bewegt wird), dann tu dies.“

Dieses Stück gehört vor </body> in die Seite oben. Dann rechnet die Seite bei jeder Reglerbewegung neu:

<script>
  const regler = document.getElementById("zins");

  function neuBerechnen() {
    const zins = Number(regler.value);
    const ergebnis = 1000 * (1 + zins / 100) ** 10;
    document.getElementById("zins-anzeige").textContent = zins;
    document.getElementById("ergebnis").textContent = Math.round(ergebnis);
  }

  regler.addEventListener("input", neuBerechnen);
</script>

Kurz gesagt: HTML ist das Gerüst, CSS die Farbe, JavaScript der Motor.

Probier es aus: „Erklär mir Zeile für Zeile, was in viz/pendel.html passiert.“ Oder: „Wo im Code wird die Energie berechnet?“

So gehst du vor

  1. Beschreiben: „Erstelle eine Datei viz/pendel.html, eine interaktive Simulation … Grundlage ist notizen/schwingungen.md.“
  2. Öffnen: Claude startet sie im Browser oder du öffnest die Datei per Doppelklick.
  3. Verbessern: „Der Regler soll bis 90° gehen.“ „Zeig zusätzlich die Energie als Kurve.“
  4. Committen, wenn es dir gefällt.
