Mehrere Agenten

Teil V · Erschaffen & visualisieren · ca. 15 Min. · Braucht: Plan-Modus, Kontextfenster

Claude kann Teilaufgaben an Subagents abgeben, z. B. einer recherchiert, einer baut, einer prüft unabhängig. Aber: Wenn sich zwei Agenten einig sind, ist das noch kein Beweis.

Beispiel: Drei Baumeister, eine Galerie

Im Ordner demos/doppelpendel/ liegt die Seite galerie.html mit drei leeren Kacheln. Jede Kachel wartet auf eine Datei. Sobald die Datei da ist, erscheint sie.

  1. Galerie im Browser öffnen. Claude startet dafür einen kleinen lokalen Server: „Starte einen lokalen Webserver und öffne demos/doppelpendel/galerie.html.“

  2. Drei Subagents gleichzeitig losschicken:

    Nutze drei Subagents parallel. Jeder baut eine Ansicht des Doppelpendels
und nutzt dafür demos/doppelpendel/physik.js:
A → demos/doppelpendel/ansicht-a.html: Animation mit Leuchtspur
B → demos/doppelpendel/ansicht-b.html: Energie über die Zeit
C → demos/doppelpendel/ansicht-c.html: zwei Pendel, Startwinkel um
    0,001° verschieden
Keiner liest die Dateien der anderen.

  3. Zuschauen: Im Terminal laufen drei Agenten nebeneinander. Im Browser füllen sich die Kacheln nacheinander, jede in ihrem eigenen Tempo.

  4. Unabhängig prüfen lassen:

    Starte einen weiteren Subagent. Er soll widerlegen, dass die Gesamtenergie
in ansicht-b.html gleich bleibt. Er rechnet selbst mit physik.js nach und
liest ansicht-b.html nicht.

Achtung: Jeder Agent verbraucht Kontingent von deinem Abo. Drei bis vier sind für so ein Beispiel in Ordnung.

Du kannst auch selbst mehrere Claude-Sessions gleichzeitig laufen lassen, z. B. eine recherchiert, eine baut die Visualisierung. Damit du den Überblick behältst, gibt es herdr: Es läuft in deinem Terminal, zeigt alle Sessions nebeneinander und in einer Seitenleiste, welcher Agent gerade arbeitet, fertig ist oder auf deine Antwort wartet. Läuft auf Mac, Linux und Windows, kostenlos und Open Source.
